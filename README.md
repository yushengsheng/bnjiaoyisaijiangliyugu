# 交易量排行榜统计器

一个无构建步骤、无后端、无数据上传的 Brave/Chrome 扩展。它在正常浏览器页面中识别排行榜接口，一次获取全榜并同时计算：全榜总交易量、前 N 名交易量、N+1 名起交易量。

## 从 GitHub Releases 安装

1. 打开项目的 [Releases 页面](https://github.com/yushengsheng/Trading-Volume-bn/releases)
2. 下载 `Trading-Volume-bn-v*.zip`
3. 将 ZIP 完整解压到一个长期保留的文件夹
4. 在 Brave 地址栏打开 `brave://extensions/`
5. 打开右上角 **开发者模式**
6. 点击 **加载已解压的扩展程序**
7. 选择解压后包含 `manifest.json` 的文件夹

> Brave 不支持直接从 GitHub 点击安装 ZIP 或 CRX。真正的一键安装和自动更新需要发布到 Chrome Web Store；GitHub Release 版本需要“解压 + 加载已解压扩展”。

## 从源码安装到 Brave

1. 在 Brave 地址栏打开 `brave://extensions/`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择**解压后的项目文件夹**（也就是包含 `manifest.json` 的文件夹）
5. 点击工具栏里的扩展图标，打开统计界面

辅助打开脚本：

- macOS：双击 `打开安装页面.command`
- Windows：双击 `打开扩展页面.bat`
- Linux：运行 `./打开扩展页面.sh`

辅助脚本只负责打开扩展管理页和项目目录；扩展本身不依赖固定安装路径。

## 使用

1. 填入排行榜网址，默认已经放入示例 ENSO1 地址。
2. “忽略前 N 名”填写 `1000`，即从第 `1001` 名开始统计。
3. 点击 **打开并连接**；如果排行榜已经手动打开，也可以点击 **连接当前网页**。
4. 如遇安全验证，手动完成即可；随后刷新一次排行榜页面。
5. 界面显示“已识别”后，点击 **开始自动统计**。
6. 手动填写 **1001 名起奖励池** 和奖励代币，例如 `80 BNB`、`100000 USDT` 或任意自定义代币；程序不会抓取公告奖励。
7. 系统会显示全榜、前 1000 名、1001 名起的交易量，并用该奖励池计算每交易 `10,000 U` 可获得的奖励。
8. 人数校验通过后可导出 CSV；本次摘要会自动加入永久历史记录。

## 两种采集模式

- **接口直采（推荐）**：复用网页已经发出的排行榜请求，只修改页码并批量读取全榜。工具会自动尝试把每页提升到 100 条，再在本地拆分前 1000 名和其余数据。
- **页面翻页模式（备用）**：当网站接口格式无法自动识别时，读取当前页面并点击“下一页”。使用前请手动切到排行榜第 1 页。

## 特点

- 数据只在本地 Brave 与扩展中处理
- 支持自定义 `http/https` 排行榜网址
- 默认低并发、失败页自动精准补采，并适配实时变化的尾页人数
- 使用“分”为单位求和，避免常见浮点累计误差
- 自动核对 `前 N 名人数 + N+1 名起人数 = 总参与人数`
- 手动自定义 1001 名起奖励池及 BNB、USDT、USDC 或任意代币单位
- 自动计算 `1001 名起奖励池 ÷（1001 名起交易额 ÷ 10,000）`
- 自动识别并可手动修改交易赛币种，例如 ENSO
- 永久保存每次成功抓取的数据摘要，同一币种的多次记录也会保留
- 历史记录按完成时间由近到远排序，每页显示 5 条并支持单条永久删除
- 每条摘要包含全榜人数/交易量、前 N 名交易量、后段人数/交易量、每万 U 奖励和完成时间
- 可导出排名、昵称、交易量、分段总和及奖励测算 CSV

## 兼容性

- 支持 Windows、macOS 和 Linux 上的新版 Brave/Chrome。
- 最低需要 Chromium 111 内核；建议将 Brave 更新到最新版。
- 扩展仅在你点击“打开并连接”后注入当前排行榜域名，不会劫持其他日常网页。
- 如果排行榜本身无法加载，可仅针对该网站将 Brave Shields 从“积极/严格”调整为标准模式，然后刷新重试。
- 排行榜跳转到其他镜像域名时，工具会自动重新连接并刷新一次目标页面。
- 完成统计后连接会保持，可直接刷新排行榜并再次统计。
- 修改“忽略前 N 名”时，如完整明细仍在内存中，会直接本地重算，不重新请求接口。

## 注意

- 采集期间不要关闭排行榜标签页。
- 如果网页改版后字段名称非常特殊，自动识别可能失败，可先使用页面翻页模式。
- 请遵守目标网站服务条款，并控制并发速度；遇到限流可将并发调为 2。

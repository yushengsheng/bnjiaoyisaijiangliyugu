## 已复现并修复的问题

| 问题 | 处理结果 |
| --- | --- |
| 首次并发读取使用同名临时文件，可能写入失败或覆盖新活动 | 使用唯一临时文件；初始化只创建缺失文件，兼容不支持硬链接的文件系统 |
| 并发更新丢失活动字段，删除后的后台更新重新写回活动和快照 | 更新及保存前的活动检查纳入串行写入队列 |
| 同时触发手动抓榜可能启动多个任务 | 在读取活动之前占用调度状态，重复任务返回 429，失败后释放状态 |
| 快照人数不是整数或与完整性元数据不符时仍可保存 | 拒绝异常人数及元数据不一致的快照 |
| JSON 顶层不是对象、逐名快照无效时返回笼统 500 | 返回 400，并保留上次成功快照 |
| 行情刷新失败后继续使用旧盘口计算利润 | 保留排行榜，停止旧盘口成本和利润估算 |
| 活动列表轮询失败抛出未处理异常 | 捕获失败并显示同步提示 |
| 空值或越界费率被静默当作零或沿用旧费率 | 明确提示并暂停估算，修正后重新读取行情；无效输入时 CSV 成本和利润保持未知 |
| 待核对规则的 CSV 导出仍显示确定奖励 | 标明规则待核对，估值保持未知 |
| 打包删除其他版本 ZIP，原生启动器构建源码未包含在包内 | 保留其他版本归档，发布包包含原生源码和构建脚本 |
| macOS 自带 zip 未写入 UTF-8 文件名标记，部分解压器读取中文入口乱码 | 同步本地文件头与目录头的 UTF-8 标记，并校验原始文件名一致性 |
| 空白 HOME 下的 macOS 临时浏览器可能触发系统钥匙串交互，导致抓榜停滞 | 使用 mock keychain 与 basic password store 隔离临时采集浏览器；不切回真实 HOME 或访问个人浏览器资料 |

# 修复与回归记录

用户口径：上榜记录已满足资格，不在本地重复判定最低 500 U。保持现有操作和数据文件结构，无新增 npm 依赖。

## 修复结果

| 原问题 | 处理方式 |
|---|---|
| 模拟量已进入排名区仍显示后段收益 | 达到当前门槛（含相等）即显示查看阶梯奖励的提示，后段奖励和对应 ROI 置为不可用；不凭部分阈值猜精确名次 |
| 无单人上限变成零奖励 | null、undefined、空值保留无上限语义，显式 0 仍为零上限 |
| 最低量检查 | 按用户确认不增加此检查，增加回归测试固定这个行为 |
| 后段均分误用交易量比例 | 保存 equal/proportional 分配方式，均分按新增一人计算；未识别的规则停止估算 |
| 缺失门槛和历史值显示为零 | 统一排除 null/undefined/空值；曲线在缺失处断开 |
| 混合奖励币用错价格 | 总奖池、阶梯与独立轮次按各自币种估值，行情失败按币种隔离 |
| 中间舍入及导出信息不足 | ROI 使用未舍入的美元奖励，CSV 增补场景状态、费率、价格、独立奖池及净收益 |
| 旧配置均分奖励预先截短 | 优先使用档位总额/人数计算单人奖励与估值，保留缺失金额的 null 语义 |
| 公告和采集的兼容性边界 | 普通活动可识别中英文倍数；多主奖池歧义标为待核对；分页需稳定身份和一致源时间，标记边界并列 |

旧配置未保存分配类型时，按原有比例分配解释；新导入的活动保存识别到的类型。对不能确认的规则暂停收益估算，仍能展示已保存的统计数据，不将不确定性转为零收益或正收益。
